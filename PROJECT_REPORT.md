# FreshTrack — Project Report
## Abstract
FreshTrack is a Python/Flask/SQLite web application that tracks food, monitors
expiry dates, records food outcomes and helps users make lower-waste decisions.

## Objectives
- Digitize household food inventory.
- Highlight approaching expiry.
- Track consumed, donated and wasted food.
- Track monetary value associated with food outcomes.
- Suggest simple recipes from available ingredients.
- Support smarter shopping.

## Modules
Authentication; Inventory; Expiry Engine; Food Lifecycle; Analytics; Smart Recipes;
Shopping List.

## Technology Stack
Python, Flask, SQLite, HTML, CSS, Jinja2 and Werkzeug password hashing.

## Future Scope
Email/SMS alerts, AI recipe generation, barcode scanning, mobile app, cloud database,
household sharing and donation-organization integration.

## Conclusion
FreshTrack demonstrates authentication, CRUD operations, database persistence,
business logic, analytics and a practical sustainability use case in one project.
